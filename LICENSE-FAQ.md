documentation rather than running code.

`LICENSE` controls.

- Quote them with attribution.

Use them commercially without a license — for example, republishing this
material as part of a paid product, a commercial course, or marketing for a
for-profit offering.

## Does this license cover the software itself?

No. Each code repository carries its own `LICENSE` and `LICENSE-FAQ.md`:

- [churchbridge-platform](https://github.com/hainesdev/churchbridge-platform)
- [churchbridge-ios](https://github.com/hainesdev/churchbridge-ios)
- [churchbridge-audio-bench](https://github.com/hainesdev/churchbridge-audio-bench)

They are all under the same PolyForm Noncommercial terms, so the practical
answer is the same — but the authoritative text for any given repository is the
one in that repository.

## Does it cover the things ChurchBridge depends on?

No. Third-party components have their own terms, recorded in each repository's
`THIRD-PARTY-NOTICES.md`. Notably, the DeepFilterNet3 signal chain is MIT, the
Core ML model conversion is Apache-2.0, and Bible translations have their own
licensing — Reina-Valera 1960 in particular is copyrighted.

No. PolyForm Noncommercial has no change date and no automatic conversion.
